# Aqualume Clinic

Aqualume is a portfolio-only Astro concept for a premium medical aesthetics and wellness clinic.

## Scope

- responsive public homepage;
- treatments overview;
- consultation-request prototype;
- portfolio disclosure, privacy and terms pages;
- responsive screenshots for portfolio presentation.

This is a visual and frontend proposal, not a live medical or booking service. The consultation form is a prototype and must be connected to a real booking or CRM workflow before production use.

## Development

```sh
npm install
npm run dev
npm run build
npm run check
```
